# 更新记录

## 1.0.0 - 2026-10-21

首个版本。

- 盯住豆瓣的热门榜单（实时热门电影 / 剧集、口碑榜、分类榜等）：新进榜的片自动建订阅。
- 电影直接订；剧集按标题里的季号订（第 N 季 / 第 N 部 / Season N / S0N），没写季号按第 1 季，
  默认打开「自动续订」和「补已播出的集」。
- 多榜单交错合并：两个榜齐头并进，不会出现「电影榜全订完才轮到剧集」。
- 可调口径：豆瓣评分下限、暂无评分的跳过与否、每个榜单只取前几名、标题排除词
  （综艺 / 短剧 / 预告；英文词按整词匹配，TC 不命中 TCA）。
- 每轮最多订阅 N 条（1～50），没订完的下一轮接着订；库里已有的自动跳过。
- 第一次同步默认「当前榜上的全都订」，也可以改成「只订以后新进榜的」。
- 豆瓣条目对应多部作品或 TMDB 暂未收录的记进「待确认」，用 `pending` / `resolve` 定，不自己瞎猜。
- 订阅成功发 `douban-hot-subscribe.subscribed` 事件，配一条被动通知。
