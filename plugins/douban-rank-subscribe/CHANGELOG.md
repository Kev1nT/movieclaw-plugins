# 豆瓣榜单订阅 更新记录

## 1.0.1

- 新增「自动订阅」总开关：关掉后定时任务不再自动下单，「立即扫描」也被拦下；
  海报上的手动「订阅」不受影响。
- 移除「实时热门电影」榜单。
- 卡片角标按统一版式规范调整：评分用 `.score`、状态用 `.status`（右上评分、底部居中状态），
  状态最多显示一个，已入库优先。状态角标配色：已订阅红底白字、已入库绿底白字。
- 分段标签右侧不再显示启用的榜单名。
- 详情弹窗：去掉 header 和右上角关闭；海报铺满顶部、模糊处理、上下渐变过渡；
  白边改为独立描边层，滚动与圆角都完整，海报与正文之间不再有分隔白线。
- 状态角标去掉小圆点，改为纯文字（配色仍为已订阅红底白字、已入库绿底白字）。
- 详情弹窗去掉「海报→标题」和「正文→按钮区」的白色分隔线，海报渐变柔和过渡到正文。
- 手机端一行三张海报，且不再显示右侧滚动条。

## 1.0.0

- 在左侧栏「豆瓣榜单」里浏览豆瓣热门/口碑榜单：海报墙点开可看详情、一键订阅。
- 后台按你勾选的榜单定期扫描，新上榜且评分达标的作品自动创建订阅。
- 支持自定义榜单地址（RSS/Atom、JSON、纯文本一行一个片名）。
- 详情弹窗含海报、评分、地区类型、上映日期、简介、演职员与相似推荐。
- 设置集中到右上角抽屉：榜单勾选、评分门槛、每榜条数、剧集订阅策略、自定义地址。
- 界面按 MovieClaw 插件页统一版式：顶栏、分段标签、海报网格、抽屉、选项弹窗、详情弹窗。
- 剧集默认只追以后播出的新集，可选改为记入待确认。
